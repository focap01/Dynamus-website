# Dynamus Training & Development Consulting — Website

Starter site for dynamustraining.com. Plain HTML/CSS/JS — no build tools required,
which keeps it simple in VS Code and easy for Claude Code to edit later.

## What's here
- `index.html` — the whole site (nav, hero, about, services, training tools, contact, footer)
- `styles.css` — all styling and the brand color/type system
- `script.js` — mobile menu + contact form handling
- `assets/logo.png`, `assets/favicon.png` — your logo, cropped and resized from the file you uploaded

## Brand palette (pulled from your logo)
- Deep purple `#2c2266` / Primary purple `#4a3aa0` / Bright purple `#5d42f5`
- Orange accent `#ee911d`
- Near-black `#14121f`
- Soft background `#fbfaff`
